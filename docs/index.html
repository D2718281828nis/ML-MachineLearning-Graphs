1A graph is a hypothesis about who influences whomГраф — это гипотеза о том, кто на кого влияет

A graph neural network gets two inputs: node features and edges. The edges are an assumption. The rest of this page is about how they enter the computation and how to test whether they earned their place.Графовая нейросеть получает на вход две вещи: признаки вершин и рёбра. Рёбра — это предположение. Вся страница о том, как они входят в вычисление и как проверить, заслужили ли они своё место.

A graphГраф $G=(V,E)$ withс $n$ nodes is stored asвершинами хранится как

  • a feature matrixматрица признаков $X\in\mathbb R^{n\times d}$: row $x_i$ describes node $i$ from its own measurements (an EEG channel, an engine sensor, a stock);: строка $x_i$ описывает вершину $i$ по её собственным измерениям (канал ЭЭГ, датчик двигателя, акция);
  • an adjacency matrixматрица смежности $A\in\{0,1\}^{n\times n}$: $A_{ij}=1$, if $i$ and $j$ are connected.если $i$ и $j$ соединены.

An MLP uses only $X$: it treats rows as independent samples. A GNN also uses $A$: each node collects messages from its neighbours, so its prediction can depend on information it does not hold itself.

MLP использует только $X$: строки для него — независимые объекты. GNN использует ещё и $A$: каждая вершина собирает сообщения от соседей, поэтому её предсказание может зависеть от информации, которой у неё самой нет.

This is useful only if the edges carry information about the target. If they don't, the GNN just has extra inputs it has to learn to ignore. That is the reason for the edge check further down.

Это полезно, только если рёбра несут информацию о целевой переменной. Если нет — у GNN просто есть лишние входы, которые ей приходится учиться игнорировать. Поэтому ниже и нужна проверка рёбер.

Why nodes A and B? They are a test built into the demo graph. A and B have exactly the same own value (0.30), but A's neighbours are all positive and B's are all negative. A model that looks only at a node's own value (an MLP, or a GNN with the edges removed) sees “0.30” twice and must give them the same answer. A GNN looks at the neighbours too, so it can tell them apart. Watching what happens to hA and hB is the quickest way to see what the edges add. The guided tour below walks through it.

Зачем вершины A и B? Это встроенный в демонстрационный граф тест. У A и B одинаковое собственное значение (0,30), но все соседи A положительные, а все соседи B отрицательные. 3GCN: averaging with fixed, degree-normalised weightsGCN: усреднение с фиксированными весами, нормированными по степеням

$$H^{(l+1)}=\sigma\big(\hat A\,H^{(l)}W^{(l)}\big),\qquad \hat A=\tilde D^{-1/2}\tilde A\,\tilde D^{-1/2},\quad \tilde A=A+I,\quad \tilde d_i=\textstyle\sum_j\tilde A_{ij}.$$
  1. Self-loop $A+I$: the node keeps its own vector in the sum; without it a node would forget itself.
  2. Петля $A+I$: вершина оставляет в сумме собственный вектор; без неё вершина «забыла» бы себя.
  3. Symmetric normalisation $1/\sqrt{\tilde d_i\tilde d_j}$: a hub does not blow up, and a message from a hub counts less, because the hub talks to everyone.
  4. Симметричная нормировка $1/\sqrt{\tilde d_i\tilde d_j}$: значения у хаба не «взрываются», а сообщение от хаба весит меньше, потому что хаб связан со всеми.
  5. Shared weights $W^{(l)}$: one matrix for all nodes, as in a convolution over pixels.
  6. Общие веса $W^{(l)}$: одна матрица для всех вершин, как свёртка по пикселям.
  7. $L$ layers = $L$ hops. Stacking many layers is repeated smoothing ($\hat A^{K}X$) and eventually makes all nodes look alike (over-smoothing).
  8. $L$ слоёв = $L$ шагов. Много слоёв — это многократное сглаживание ($\hat A^{K}X$), которое в итоге делает все вершины похожими (пересглаживание).
Read the matrix in the playground. In GCN mode the matrix panel shows $\hat A$. It is computed from the graph alone and stays the same at every layer and for every input. The network can scale messages through $W$, but it can't choose which neighbour to listen to.Посмотрите на матрицу в песочнице. В режиме GCN панель показывает $\hat A$. Она вычисляется только по графу и одинакова на всех слоях и для любых входов. Сеть может масштабировать сообщения через $W$, но не может выбирать, какого соседа слушать.

4The graph Laplacian: how much a signal changes across edgesЛапласиан графа: насколько сигнал меняется вдоль рёбер

Put one number $x_i$ on every node; this vector $x$ is a graph signal. The Laplacian is the matrix that measures how different each node is from its neighbours. Everything spectral (Fourier, spectral convolution, and in the end GCN) is built on it.Запишем в каждую вершину число $x_i$; вектор $x$ — это сигнал на графе. Лапласиан — матрица, которая измеряет, насколько каждая вершина отличается от соседей. На нём построено всё спектральное: Фурье, спектральная свёртка и в итоге GCN.

$$L=D-A,\qquad D=\operatorname{diag}(d_1,\dots,d_n),\quad d_i=\textstyle\sum_j A_{ij}$$
$$(Lx)_i=d_ix_i-\sum_{j\in\mathcal N(i)}x_j=\sum_{j\in\mathcal N(i)}\big(x_i-x_j\big)$$
$$x^{\top}Lx=\sum_{(i,j)\in E}\big(x_i-x_j\big)^2\ \ge 0$$
$$L_{\text{sym}}=I-D^{-1/2}AD^{-1/2},\qquad \lambda(L_{\text{sym}})\in[0,2]$$
  1. Row $i$ of $Lx$ is “node minus its neighbours”: the discrete analogue of the second derivative $-f''$. On a path graph it is exactly $-(x_{i+1}-2x_i+x_{i-1})$.
  2. Строка $i$ вектора $Lx$ — «вершина минус её соседи»: дискретный аналог второй производной $-f''$. На графе-пути это ровно $-(x_{i+1}-2x_i+x_{i-1})$.
  3. $x^{\top}Lx$ is the total variation (Dirichlet energy) of the signal: small if neighbours have similar values, large if values jump across edges. The red edges in the demo are its terms.
  4. $x^{\top}Lx$ — полная вариация (энергия Дирихле) сигнала: мала, если у соседей близкие значения, и велика, если значения скачут вдоль рёбер. Красные рёбра в демонстрации — её слагаемые.
  5. $L$ is symmetric and positive semi-definite, so it has real eigenvalues $0=\lambda_1\le\lambda_2\le\dots\le\lambda_n$ and orthonormal eigenvectors. $L\mathbf 1=0$: a constant signal has zero variation.
  6. $L$ симметрична и неотрицательно определена, поэтому её собственные значения вещественны, $0=\lambda_1\le\lambda_2\le\dots\le\lambda_n$, а собственные векторы ортонормированы. $L\mathbf 1=0$: у постоянного сигнала вариация нулевая.
  7. Number of zero eigenvalues = number of connected components. $\lambda_2$ (the Fiedler value) measures how well the graph is connected, and the signs of its eigenvector $u_2$ split the graph into two parts (spectral clustering).
  8. Число нулевых собственных значений = числу компонент связности. $\lambda_2$ (число Фидлера) показывает, насколько хорошо граф связан, а знаки его собственного вектора $u_2$ делят граф на две части (спектральная кластеризация).

Link to GNNs. One step of Laplacian smoothing, $x\leftarrow x-\varepsilon Lx$, moves each node towards the average of its neighbours; this is message passing. GCN's $\hat A$ is exactly $I-\tilde L_{\text{sym}}$ for the graph with self-loops (next section). Что попробовать. (1) «гладкий (u₂)» на двух сообществах: одно сообщество положительное, другое отрицательное, красный только мост 0–6. Это спектральная кластеризация. (2) «постоянный»: $x^{\top}Lx=0$. (3) «резкий (uₙ)»: красные почти все рёбра. (4) Править рёбра и удалить мост 0–6: при λ = 0 появляется вторая красная точка — у графа стало две компоненты. (5) Переключите матрицу на A, D, L и убедитесь, что сумма каждой строки L равна 0.

Связь с GNN. Один шаг лапласова сглаживания $x\leftarrow x-\varepsilon Lx$ сдвигает каждую вершину к среднему её соседей — это и есть передача сообщений. Матрица $\hat A$ в GCN — это ровно $I-\tilde L_{\text{sym}}$ для графа с петлями (следующий раздел).

5Graph Fourier transform and spectral convolutionПреобразование Фурье на графе и спектральная свёртка

On a line, sines and cosines are the eigenfunctions of the second derivative, and their frequencies say how fast they oscillate. On a graph, the eigenvectors of the Laplacian play the same role, and the eigenvalue $\lambda_k$ is the frequency. This gives a Fourier transform on any graph, and convolution as multiplication in the spectrum. GCN is a cheap approximation of exactly that.На прямой синусы и косинусы — собственные функции второй производной, а их частота показывает, как быстро они колеблются. На графе ту же роль играют собственные векторы лапласиана, а собственное значение $\lambda_k$ — это частота. Так получается преобразование Фурье на любом графе, а свёртка — умножение в спектре. GCN — дешёвое приближение именно этого.

1 · Fourier basis = eigenvectors of the Laplacian1 · Базис Фурье = собственные векторы лапласиана

$$L=U\Lambda U^{\top},\quad U=[u_1,\dots,u_n],\quad \Lambda=\operatorname{diag}(\lambda_1,\dots,\lambda_n),\qquad u_k^{\top}Lu_k=\lambda_k$$
$$\hat x=U^{\top}x\ \ (\text{GFT}),\qquad x=U\hat x=\sum_k\hat x_k\,u_k\ \ (\text{inverse})$$
  • $\hat x_k=\langle u_k,x\rangle$ is how much of “frequency” $\lambda_k$ the signal contains.
  • Small $\lambda_k$: $u_k$ changes slowly across edges (few sign changes). Large $\lambda_k$: it flips sign across most edges.
  • On the cycle graph the eigenvectors are exactly sampled sines and cosines and $\lambda_k=2-2\cos(2\pi k/n)$: the classical discrete Fourier transform is a special case.
  • In this section we use $\tilde L=I-\tilde D^{-1/2}(A+I)\tilde D^{-1/2}$, the normalised Laplacian of the graph with self-loops, because then GCN's $\hat A$ is exactly $I-\tilde L$.
  • $\hat x_k=\langle u_k,x\rangle$ — сколько в сигнале «частоты» $\lambda_k$.
  • Малое $\lambda_k$: $u_k$ медленно меняется вдоль рёбер (мало смен знака). Большое $\lambda_k$: знак меняется почти на каждом ребре.
  • На графе-цикле собственные векторы — ровно дискретные синусы и косинусы, а $\lambda_k=2-2\cos(2\pi k/n)$: классическое дискретное преобразование Фурье — частный случай.
  • В этом разделе используется $\tilde L=I-\tilde D^{-1/2}(A+I)\tilde D^{-1/2}$ — нормированный лапласиан графа с петлями, потому что тогда матрица $\hat A$ из GCN равна ровно $I-\tilde L$.

● sign change on an edgeсмена знака на ребреbottom: all eigenvalues, the current one highlightedвнизу: все собственные значения, текущее выделено

2 · Spectral convolution = filtering frequencies2 · Спектральная свёртка = фильтрация частот

$$x *_G g\;=\;U\big((U^{\top}g)\odot(U^{\top}x)\big)\;=\;U\,g_\theta(\Lambda)\,U^{\top}x$$

As in signal processing, convolution becomes multiplication in the frequency domain: transform, multiply each frequency by $g(\lambda_k)$, transform back. A low-pass filter keeps the smooth part of the signal and removes noise that jumps across edges.

Как в цифровой обработке сигналов, свёртка превращается в умножение в частотной области: преобразовать, умножить каждую частоту на $g(\lambda_k)$, преобразовать обратно. Фильтр низких частот сохраняет гладкую часть сигнала и убирает шум, который скачет вдоль рёбер.

From spectral filters to GCN in three stepsОт спектральных фильтров к GCN за три шага

  1. Spectral CNN (Bruna et al., 2014): learn $g_\theta=\operatorname{diag}(\theta_1,\dots,\theta_n)$ directly. Needs the eigendecomposition ($O(n^3)$), $n$ parameters per filter, filters are not localised and don't transfer to another graph.
  2. Spectral CNN (Bruna и др., 2014): обучать $g_\theta=\operatorname{diag}(\theta_1,\dots,\theta_n)$ напрямую. Нужно разложение по собственным векторам ($O(n^3)$), $n$ параметров на фильтр, фильтры не локальны и не переносятся на другой граф.
  3. ChebNet (Defferrard et al., 2016): make $g$ a polynomial of degree $K$. A polynomial of $\Lambda$ inside $U\cdot U^{\top}$ is the same polynomial of $L$, so no eigenvectors are needed, and $L^K$ only reaches $K$ hops: the filter is $K$-hop localised.
    $$U\Big(\sum_{k=0}^{K}\theta_kT_k(\bar\Lambda)\Big)U^{\top}x=\sum_{k=0}^{K}\theta_kT_k(\bar L)\,x,\qquad \bar L=\tfrac{2}{\lambda_{\max}}L-I$$
  4. ChebNet (Defferrard и др., 2016): сделать $g$ многочленом степени $K$. Многочлен от $\Lambda$ внутри $U\cdot U^{\top}$ — это тот же многочлен от $L$, поэтому собственные векторы не нужны, а $L^K$ дотягивается только на $K$ шагов: фильтр локален в $K$-окрестности.
    $$U\Big(\sum_{k=0}^{K}\theta_kT_k(\bar\Lambda)\Big)U^{\top}x=\sum_{k=0}^{K}\theta_kT_k(\bar L)\,x,\qquad \bar L=\tfrac{2}{\lambda_{\max}}L-I$$
  5. GCN (Kipf & Welling, 2017): take $K=1$, $\lambda_{\max}\approx2$ and a single parameter $\theta=\theta_0=-\theta_1$, then apply the renormalisation trick (add self-loops):
    $$\theta_0x+\theta_1(L_{\text{sym}}-I)x=\theta\big(I+D^{-1/2}AD^{-1/2}\big)x\ \longrightarrow\ \theta\,\tilde D^{-1/2}\tilde A\tilde D^{-1/2}x=\theta\,\hat Ax$$
    Since $\hat A=I-\tilde L$, one GCN layer is the spectral filter $g(\lambda)=1-\lambda$, a low-pass filter. $K$ layers give $(1-\lambda)^K$: more layers, stronger smoothing, and eventually over-smoothing.
  6. GCN (Kipf, Welling, 2017): взять $K=1$, $\lambda_{\max}\approx2$ и один параметр $\theta=\theta_0=-\theta_1$, затем применить трюк перенормировки (добавить петли):
    $$\theta_0x+\theta_1(L_{\text{sym}}-I)x=\theta\big(I+D^{-1/2}AD^{-1/2}\big)x\ \longrightarrow\ \theta\,\tilde D^{-1/2}\tilde A\tilde D^{-1/2}x=\theta\,\hat Ax$$
    Поскольку $\hat A=I-\tilde L$, один слой GCN — это спектральный фильтр $g(\lambda)=1-\lambda$, фильтр низких частот. $K$ слоёв дают $(1-\lambda)^K$: чем больше слоёв, тем сильнее сглаживание, а в пределе — пересглаживание.

Why this matters for the edge check. A GCN is a low-pass filter on the given graph. It helps exactly when the useful signal is low-frequency on that graph, i.e. when neighbours tend to share the label (homophily). If the label signal is high-frequency (heterophily), or the edges are unrelated to it (random or wrong edges), low-pass filtering removes signal instead of noise, and ΔG ≈ 0 or below zero, as in the lab. The spectrum of the graph is a hypothesis too. Почему это важно для проверки рёбер. GCN — фильтр низких частот на данном графе. Он помогает ровно тогда, когда полезный сигнал на этом графе низкочастотный, то есть соседи обычно имеют одну метку (гомофилия). 6GAT / GATv2: the network learns whom to listen toGAT / GATv2: сеть учится, кого слушать

$$e_{ij}=a^{\top}\,\mathrm{LeakyReLU}\big(W[h_i\,\|\,h_j]\big),\qquad \alpha_{ij}=\frac{\exp e_{ij}}{\sum_{k\in\mathcal N(i)\cup\{i\}}\exp e_{ik}},\qquad h_i'=\sigma\Big(\sum_{j}\alpha_{ij}\,W h_j\Big).$$
  • The weights $\alpha_{ij}$ depend on the features of both ends, so they change from input to input and from layer to layer.
  • Each row of $\alpha$ is a probability distribution over the neighbourhood (it sums to 1).
  • GATv2 applies the nonlinearity before the dot product with $a$. In the original GAT it came after, which made the ranking of neighbours the same for every query node (“static attention”).
  • Веса $\alpha_{ij}$ зависят от признаков обеих вершин, поэтому меняются от входа к входу и от слоя к слою.
  • Каждая строка $\alpha$ — распределение вероятностей по окрестности (сумма равна 1).
  • В GATv2 нелинейность применяется до скалярного произведения с $a$. В исходном GAT — после, из-за чего порядок соседей был одинаковым для любой вершины («статическое внимание»).

Switch the playground to GATv2 and change a neighbour's feature with the slider: the strokes and the matrix rows change, while in GCN they don't. The demo uses fixed parameters that favour neighbours similar to the receiving node; a trained model would learn $W$ and $a$.

Переключите песочницу на GATv2 и измените признак соседа ползунком: штрихи и строки матрицы меняются, а в GCN — нет. В демонстрации параметры фиксированы и предпочитают соседей, похожих на принимающую вершину; обученная модель выучила бы $W$ и $a$ сама.

Attention as an explanation for “where”. It is tempting to read $\alpha_{ij}$ as “node $i$’s decision came from neighbour $j$” and to rank a source node this way. That reading assumes the edges carry information. If the network does just as well with no neighbours ($\Delta_G\approx0$), the weights only describe how the network spread its attention, not where an event came from. Внимание как объяснение «где». Соблазнительно читать $\alpha_{ij}$ как «решение вершины $i$ пришло от соседа $j$» и так ранжировать источник. Такое прочтение предполагает, что рёбра несут информацию. Если сеть справляется не хуже без соседей ($\Delta_G\approx0$), веса описывают лишь то, как сеть распределила внимание, а не откуда пришло событие.

11Hyperbolic graphs: room for treesГиперболические графы: место для деревьев

In a tree with branching $b$ the number of nodes at depth $d$ grows like $b^{d}$, but a Euclidean circle's length grows only linearly in its radius. Hyperbolic space grows exponentially, so trees and hierarchies embed with little distortion.В дереве с ветвлением $b$ число вершин на глубине $d$ растёт как $b^{d}$, а длина евклидовой окружности растёт лишь линейно по радиусу. Гиперболическое пространство растёт экспоненциально, поэтому деревья и иерархии вкладываются в него с малым искажением.

The Poincaré ballШар Пуанкаре

$$\mathbb B^n_c=\{x:\ c\|x\|^2<1\},\qquad d_{\mathbb B}(x,y)=\operatorname{arcosh}\!\Big(1+\frac{2\|x-y\|^2}{(1-\|x\|^2)(1-\|y\|^2)}\Big)\ \ (c=1)$$
  • Distances blow up near the boundary. Equal-looking gaps near the rim are huge, which is where the leaves live.
  • Shortest paths (geodesics) are arcs orthogonal to the boundary, drawn as the tree edges on the right disk.
  • Dragging applies a Möbius translation $z\mapsto\frac{z+a}{1+\bar a z}$, an isometry: the picture changes, but all hyperbolic distances stay the same. Any node can be brought to the centre.
  • Расстояния резко растут у границы. Одинаковые на вид промежутки у края огромны — именно там живут листья.
  • Кратчайшие пути (геодезические) — дуги, перпендикулярные границе; так нарисованы рёбра дерева на правом диске.
  • Перетаскивание применяет сдвиг Мёбиуса $z\mapsto\frac{z+a}{1+\bar a z}$ — изометрию: картинка меняется, а все гиперболические расстояния сохраняются. Любую вершину можно перенести в центр.

The same edge check applies. Hyperbolic geometry helps if the data is tree-like. Whether the edges help is still measured by ΔG against the identical model with A = ∅. Гиперболическая геометрия помогает, если данные древовидны. Помогают ли рёбра — по-прежнему измеряется ΔG относительно той же модели с A = ∅. На данных наложения (overlay) из репозитория гиперболическая GCN не лучше обычного k-NN классификатора, потому что лишь 33 % рёбер красной вершины ведут к красным.
